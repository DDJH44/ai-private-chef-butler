# AI 质量回归集

## 目的

用固定的合成场景检查安全边界、偏好执行、意图分流和机器可读输出。它不要求模型逐字匹配参考答案，也不把字符串规则当成语义正确性的证明。

## 用例与响应

- 用例保存在 `tests/ai_eval_cases.jsonl`；每行包含唯一 `id`、类别、场景说明、用户请求和断言。
- 评估响应必须由人工从待测环境采集，并保存为 JSONL，每行格式为 `{"id":"用例ID","response":"模型实际响应"}`。
- 使用合成场景，不要把真实用户对话、照片、过敏或体征数据加入仓库。

## 运行

```powershell
D:/Develop/python/python.exe -m pytest tests/test_ai_quality_regression.py
D:/Develop/python/python.exe tests/ai_eval.py --responses path/to/responses.jsonl
```

评估器只读本地 JSONL，不初始化 Agent、不访问模型或数据库。任何缺失的用例响应、未知 ID 或断言失败都会令命令返回非零状态。

## 断言边界

当前断言只覆盖明确可程序化检查的要求：必要/禁止短语、是否输出菜谱保存块、保存块食材禁忌，以及营养 JSON 的必需字段和数值类型。它无法可靠判断营养学结论是否正确、回答是否真正个性化，也无法验证模型声称的来源是否真实；这些项目需人工复核。后续应把线上发现的问题（经脱敏和合成改写）纳入用例，并在更换模型或提示词后比较结果，而不是直接存储用户原始对话。
