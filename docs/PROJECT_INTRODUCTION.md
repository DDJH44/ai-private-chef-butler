# AI 私人厨师管家 — 项目介绍

## 项目概述

AI 私人厨师管家是一套面向家庭餐饮管理的智能系统，以 AI Agent 为核心，将菜谱推荐、膳食计划、营养分析、冰箱库存、购物清单和飞书推送整合为统一体验。用户通过自然语言对话即可完成从"今天吃什么"到"这周怎么吃"的全链路决策，拍照即可识别食材入库、分析餐食营养。

## 技术栈

**后端**：Python FastAPI + LangGraph Agent 状态机，以小米 MIMO / 豆包作为主力 LLM，通过 SSE 实现流式对话。数据库层采用 SQLAlchemy + MySQL 8.0，LangGraph 检查点直接持久化到 MySQL，无需额外基础设施。

**AI 能力**：混合 RAG 检索引擎（ChromaDB 稠密检索 + BM25 稀疏检索，BGE 中文嵌入 + jieba 分词），覆盖营养学数据库、菜谱知识库和健身知识三大领域；多模态视觉识别支撑食材拍照入库和餐食营养分析；豆包 Seedream 模型按需生成菜品图片。

**前端**：Next.js 16 + React 19 + TypeScript + Tailwind CSS 4，响应式设计适配桌面和移动端，通过轻量发布-订阅模式管理状态，生产环境导出静态文件由 FastAPI 统一托管。

**基础设施**：Docker Compose 一键部署（MySQL + FastAPI + Nginx 反向代理），阿里云 OSS 对象存储，飞书 Webhook 消息推送，OpenAI Whisper / TTS 语音交互。

## 功能模块

| 模块 | 核心能力 |
|------|----------|
| **AI 对话** | LangGraph 驱动的多轮对话 Agent，支持工具调用（RAG 搜索、B 站视频、图片生成），上下文感知用户偏好与冰箱库存 |
| **菜谱管理** | 菜谱 CRUD、批量操作、标签分类、模糊搜索，AI 对话中一键保存菜谱 |
| **膳食计划** | AI 并行生成 7 天三餐计划，按饮食类型和热量目标定制，仅增量生成避免重复 |
| **营养追踪** | 拍照识别食物 → RAG 增强营养数据 → 每日汇总 → AI 健康评分（0-100） |
| **冰箱库存** | 食材 CRUD + 拍照识别入库，保质期追踪与过期提醒 |
| **购物清单** | 清单管理 + 乐观锁防冲突的勾选机制，全选自动归档 |
| **烹饪历史** | 记录已做菜品、评分与备注，驱动个性化推荐 |
| **偏好设置** | 过敏原严格规避、饮食类型、口味滑块（辣/咸/甜/油）、家庭成员画像 |
| **飞书推送** | 每日饮食报告推送（营养概览 + 健康评分 + 餐食详情），菜谱分享卡片 |
| **语音交互** | Whisper 语音转文字输入，TTS 文字转语音输出 |
| **身体指标** | 体重、体脂率、肌肉量、腰围追踪，趋势图表 |

## 未来发展展望

当前系统已完成家庭餐饮场景的核心闭环，但仍有显著的扩展空间：

**从"管家"到"教练"**：引入可穿戴设备数据（运动手环、体脂秤 API），结合当前营养摄入与运动消耗，提供动态热量平衡建议，实现真正的健康管理闭环。

**多模态交互升级**：接入实时语音对话能力，让用户在厨房边做饭边通过语音查询步骤、调整用量；利用视觉模型识别烹饪过程中的食材状态，给出火候和调味建议。

**社区与知识共享**：构建用户菜谱分享平台，基于协同过滤和知识图谱实现跨用户推荐；沉淀高质量 UGC 内容反哺 RAG 知识库。

**智能硬件联动**：对接智能冰箱、智能灶具等 IoT 设备，实现库存自动同步和烹饪参数自动设定，让 AI 真正融入厨房物理空间。

**商业化路径**：SaaS 多租户架构 + 会员订阅模式，接入生鲜电商 API 实现一键下单补货，与健康管理机构合作提供企业级膳食管理方案。

技术层面，未来可探索 Agent 间的协作编排（多 Agent 分别负责营养、配餐、采购），引入更轻量的端侧模型降低推理延迟，以及通过强化学习持续优化推荐策略。AI 私人厨师管家的终局不是冷冰冰的工具，而是懂你口味、关心你健康、陪伴你每一次烹饪的厨房伙伴。
